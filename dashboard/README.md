# แดชบอร์ดคำสั่งซื้อร้านออนไลน์

หน้าเว็บ React ไฟล์เดียว (`index.html`) สำหรับผู้จัดการร้าน
1. กด **อัปโหลด orders.csv** (UTF-8 มี BOM ได้)
2. กด **อัปโหลด products.csv** เพื่อใช้ `unit_cost` คำนวณกำไรขั้นต้น (ไม่บังคับ)

ไฟล์อ่านด้วย PapaParse และคำนวณในเบราว์เซอร์ทั้งหมด ไม่มีข้อมูลฝังอยู่ในโค้ด

## ตัวกรอง
ภูมิภาค · หมวดสินค้า · ช่องทาง · ช่วงเดือน (ตั้งแต่–ถึง) ทุกตัวกรองมีผลกับการ์ด KPI, กราฟทั้งหมด, แท็บวันเมกะเซล, จำนวนแต่ละ status และ JSON ของบทสรุปผู้บริหาร
กราฟรายเดือนเรียงตามเวลา เดือนที่ไม่มียอดในตัวกรองแสดงเป็น ฿0

## นิยาม
- **ยอดขายสุทธิ** = `qty × unit_price × (1 − discount_pct/100)` เฉพาะ `status = "จัดส่งสำเร็จ"` ไม่รวม `shipping_fee`
- **คำสั่งซื้อสำเร็จ** = จำนวน `order_id` ที่ `status = "จัดส่งสำเร็จ"`
- **AOV** = ยอดขายสุทธิ ÷ คำสั่งซื้อสำเร็จ
- **อัตรายกเลิก** = คำสั่งซื้อ `"ยกเลิก"` ÷ คำสั่งซื้อทั้งหมด (รวม "คืนสินค้า" ในตัวหาร)
- **กำไรขั้นต้น** = ยอดขายสุทธิ − `qty × unit_cost` (unit_cost จาก `products.csv` เชื่อมด้วย `product_id`) เฉพาะคำสั่งซื้อสำเร็จ
- **% กำไรขั้นต้น** = กำไรขั้นต้น ÷ ยอดขายสุทธิ
- **วันเมกะเซล** = 3.3, 6.6, 9.9, 10.10, 11.11, 12.12 (วันที่ตรงกับเลขเดือน) · **วันปกติ** = วันอื่นที่มีคำสั่งซื้อ

## บทสรุปผู้บริหาร
ปุ่ม **สรุปให้ผู้บริหาร** ส่ง JSON ตัวเลขสรุป (ไม่เกิน 30 ค่า ไม่มีข้อมูลรายแถว) ให้ Claude เขียนบทสรุป 5 บรรทัดภาษาไทย
หน้าเว็บตรวจตัวเลขทุกตัวในคำตอบกับ JSON และไฮไลต์บรรทัดที่มีตัวเลขไม่อยู่ใน JSON
ปุ่มนี้ใช้ได้เฉพาะเมื่อเปิดหน้าใน claude.ai (Artifact) เมื่อเปิดไฟล์นี้ตรง ๆ หรือผ่าน GitHub Pages ปุ่มจะถูกปิดไว้
