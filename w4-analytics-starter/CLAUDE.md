# บ้านสบาย ช็อป · โปรเจกต์วิเคราะห์ยอดขาย

ร้านค้าออนไลน์สมมติ ข้อมูลปีงบ 1 ต.ค. 2025 – 30 ก.ย. 2026 อยู่ในโฟลเดอร์ `data/`

## นิยาม (ห้ามเปลี่ยน)

- **ยอดขายสุทธิ (net sales)** = `qty × unit_price × (1 − discount_pct/100)` เฉพาะแถวที่ `status == "จัดส่งสำเร็จ"` ไม่รวม `shipping_fee`
- **กำไรขั้นต้น** = ยอดขายสุทธิ − `qty × unit_cost` (unit_cost อยู่ใน `data/products.csv` เชื่อมด้วย `product_id`)
- **AOV** = ยอดขายสุทธิเฉลี่ยต่อคำสั่งซื้อที่จัดส่งสำเร็จ
- **อัตรายกเลิก / อัตราคืน** = จำนวนแถวสถานะนั้น ÷ จำนวนคำสั่งซื้อทั้งหมดในกลุ่มที่สนใจ × 100
- **เดือน** = 7 ตัวอักษรแรกของ `order_datetime` (YYYY-MM) · **วันที่** = 10 ตัวอักษรแรก
- `ship_days` ว่างได้ (คำสั่งซื้อที่ยกเลิก) · `rating` ว่างได้ (ลูกค้าไม่รีวิว) ให้ตัดค่าว่างออกก่อนเฉลี่ย
- ไฟล์ CSV เป็น UTF-8 มี BOM อ่านด้วย `encoding="utf-8-sig"`

## กติกาการทำงาน

1. **ห้ามแก้ไฟล์ใน `tests/`** ถ้าคิดว่า test ผิด ให้หยุดและอธิบายเหตุผล
2. **ห้าม hard-code ตัวเลขคำตอบ** ทุกฟังก์ชันต้องคำนวณจาก DataFrame ที่รับเข้ามา (test มีการเรียกกับ `orders_sample_80.csv` ด้วย)
3. ฟังก์ชันใน `src/metrics.py` รับ `df` เป็นพารามิเตอร์แรกเสมอ และอ่านอย่างเดียว ห้ามแก้ไขหรือลบข้อมูล
4. รัน `pytest -q` หลังแก้ไขทุกครั้ง แล้วสรุปเป็นภาษาไทยว่าแก้อะไรและผลเป็นอย่างไร
5. ห้ามใส่ API key หรือข้อมูลลับในโค้ดหรือ commit ให้อ่านจาก environment variable เท่านั้น

## คำสั่ง

```bash
pip install -r requirements.txt
pytest -q
```
